## TBKK

**Pet-проект**
**Жанр:** 3D Puzzle-Adventure с элементами симуляции
**Моя роль:** Unity Developer
**Команда:** один я
**Год:** 2026
**Стек:** Unity, C#, Git, NavMesh, QuickOutline
**Платформа:** Windows
**GitHub:** [github.com/bhgou/TBKK](https://github.com/bhgou/TBKK)

### Об игре

TBKK — это 3D-игра от третьего лица в жанре puzzle-adventure, действие которой происходит в городской/индустриальной среде. Игрок управляет персонажем с помощью click-to-move механики, исследует локацию с движущимися машинами, светофорами, конвейерными лентами и NPC на патрульных маршрутах. Основной геймплей строится вокруг решения головоломок через Drag-and-Drop предметов из инвентаря на интерактивные объекты мира.

Игроку необходимо собирать предметы, открывать турникеты с помощью карточки-ключа, проходить мини-игру со считывателем карт, взаимодействовать с NPC через диалоговую систему — и при этом уворачиваться от машин, которые могут сбить персонажа.

### Что я сделал

-   **Core-геймплей:** механика click-to-move с Lerp-интерполяцией и анимацией ходьбы
-   **AI машин:** движение машин по маршруту с Raycast-детекцией препятствий, светофоров и игрока
-   **Система светофоров:** циклическое переключение цветов по таймеру, синхронизация с поведением машин
-   **Инвентарь:** Singleton-менеджер с UI сеткой, ScriptableObject предметы (Id + Icon), Drag-and-Drop на объекты мира
-   **Головоломка с турникетом:** приём карточки-ключа, мини-игра со swipe-карты по считывателю, открытие двери (анимация)
-   **Диалоговая система:** ScriptableObject диалоги с именем/аватаром/текстом, UI для отображения
-   **NPC патруль:** передвижение агентов по NavMesh через waypoints
-   **Конвейерная лента:** движущиеся объекты на ленте с зацикливанием
-   **Подсветка объектов:** система Outline при приближении игрока к интерактивному объекту
-   **Main Menu:** загрузка / сброс сцены

### Технические решения

#### Drag-and-Drop система использования предметов

-   **Проблема:** Нужно дать игроку возможность интуитивно использовать предметы из инвентаря на объектах мира без сложных меню.
-   **Решение:** Реализовал перетаскивание предмета из UI Cell с Raycast-проверкой при отпускании. Если под курсором оказывается объект с `UseItemInventoryObject`, вызывается его `Use()`.
-   **Эффект:** Простой и наглядный интерфейс взаимодействия без лишних кликов.

#### Car AI + Traffic Light Sync

-   **Проблема:** Машины должны ездить по дорогам, реагировать на светофоры и не врезаться друг в друга и игрока.
-   **Решение:** Каждая машина использует Raycast вперёд — при обнаружении "Stop" триггера (зелёный свет) или End триггера (край карты) останавливается или зацикливается. Машины также детектят коллизию с игроком и вызывают смерть персонажа.
-   **Эффект:** Машины адекватно движутся по маршруту, реагируют на светофоры и представляют угрозу для игрока.

### Об игре

Horror Project — хоррор-игра от третьего лица на HDRP. Игрок исследует мрачные локации (в помещении и на открытом воздухе), взаимодействует с предметами, решает головоломки, использует оружие и уклоняется от угроз. Проект на ранней стадии разработки.

### Что я сделал

-   **Архитектура:** ServiceLocator вместо God-класса, Event-driven системы
-   **Контроллер:** ThirdPersonController + CameraMouseLook + PlayerAnimator
-   **Input System:** гибкая система привязки клавиш через InputSettings/InputPreset
-   **Оружие:** система Weapon с анимациями и стрельбой
-   **Инвентарь:** Inventory + InventorySlot + InventoryUI
-   **Взаимодействие:** SitController (сидение/вставание), IInteractable, UseSystem
-   **Локации:** LocationManager + LocationData + переходы между локациями
-   **Камера:** Cinemachine с LocationCameraHandler
-   **Звук:** SoundManager, LocationSoundHandler
-   **UI:** Dark Horror UI, экранные индикаторы, подсказки
-   **Визуальные эффекты:** PSX-эффекты, VHSPro (ленточный VHS-эффект), Outline

### Технические решения

#### Переход от God-класса к ServiceLocator

-   **Проблема:** God-класс `G.cs` со статическими ссылками на все системы делал код связанным и сложным для расширения.
-   **Решение:** Внедрил `ServiceLocator` — системы регистрируются через `ServiceLocator.Register<T>()`, получаются через `ServiceLocator.Get<T>()`. Системы общаются через `EventManager` вместо прямых вызовов.
-   **Эффект:** Код стал модульным, легко добавлять/заменять системы без изменения десятков файлов.

## Cube Collector

**Pet-проект**
**Жанр:** Hyper-Casual 3D collectator для Yandex Games
**Моя роль:** Unity Developer
**Команда:** один я
**Год:** 2026
**Стек:** Unity, C#, URP, Git, DOTween, Yandex SDK (PluginYourGames), ServiceLocator, EventManager, PlayerPrefs
**Платформа:** WebGL (Yandex Games)
**GitHub:** [github.com/bhgou/cube-collector](https://github.com/bhgou/cube-collector)

### Об игре

Cube Collector — hyper-casual 3D-игра, где игрок собирает кубики, проходит уровни и зарабатывает монеты. Проект ориентирован на публикацию в Yandex Games: реализована экономика, магазин бустеров, ежедневный бонус, комбо-система, реклама (Rewarded + Interstitial) и полный цикл WebGL-сборки.

### Что я сделал

-   **Экономика:** MoneyManager (синглтон, PlayerPrefs), выдача монет за уровень, UI монет в HUD
-   **Магазин:** ShopController + ShopManager, префаб Shop из GUI Pro-CasualGame
-   **Бустеры:** ExtraMoves (+3 хода), Magnet, бустеры через PowerUpManager
-   **Реклама:** YandexAdsProxy (заглушка/продакшн), Rewarded за доп. ходы и удвоение монет, Interstitial каждый 3-й уровень
-   **Ежедневный бонус:** DailyBonusManager (7 дней, нарастающие награды)
-   **Комбо-система:** множитель монет за уровни подряд (comboMultiplier = 1 + comboCount * 0.5f)
-   **UI:** все анимации на DOTween (HyperCasual-стиль: быстро, упруго, пружинисто, каскадно)
-   **Визуал:** частицы VFX, линии притяжения для Magnet, DOTween-анимации интерфейса
-   **WebGL:** билд под Yandex Games, подключение SDK, WebGL-шаблон
-   **Архитектура:** ServiceLocator + EventManager (архитектура перенесена из Horror Project)

### Технические решения

#### HyperCasual UI на DOTween

-   **Проблема:** Интерфейс выглядел статично, не хватало «отзывчивости» в hyper-casual стиле.
-   **Решение:** Все анимации переведены на DOTween — появление панелей (Scale с OutBack), пульсация кнопок (PunchScale), каскадное появление элементов с задержками, анимированный счёт (DOTween.To).
-   **Эффект:** UI стал быстрым, упругим и отзывчивым — характерный hyper-casual feel.

#### Экономика и Yandex Games интеграция

-   **Проблема:** Игра должна монетизироваться через Yandex Games — реклама, покупки, лидерборды.
-   **Решение:** Создал YandexAdsProxy с заглушкой для тестов и реальным SDK для продакшна. Интегрировал PluginYourGames. Привязал экономику (монеты, бустеры) к рекламным точкам: удвоение награды, доп. ходы при проигрыше, Interstitial между уровнями.
-   **Эффект:** Полный цикл монетизации без блокировки геймплея.
